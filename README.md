# Golden Satoshi (GS) - A Decentralized Tribute to Satoshi Nakamoto

Golden Satoshi (GS) is an independent, community-driven initiative built on the BNB Smart Chain (BSC). Created as an authentic tribute to Satoshi Nakamoto—the father of cryptocurrency—GS honors the foundational principles of peer-to-peer financial freedom, absolute transparency, and true scarcity.

By capping the total supply at exactly 21,000,000 GS, the project directly mirrors Bitcoin's iconic scarcity model while leveraging modern smart contract logic to protect community liquidity.

## Core Philosophy & Key Features
- **Historical Tribute:** Designed in honor of Satoshi Nakamoto to champion financial sovereignty and decentralization.
- **Fixed Supply (21M):** Capped total supply of 21,000,000 GS, ensuring no minting or inflation.
- **Automated Anti-Dump Mechanism:**
  - Small Sells (<10,000 GS): 2% tax allocated to Development & Infrastructure.
  - Large Sells (>=10,000 GS): 15% tax allocated directly to the Liquidity Pool.
- **Zero Buy Tax:** 0% tax on purchases to encourage organic ecosystem growth.
- **Pure Wallet Transfer:** 0% tax on peer-to-peer wallet-to-wallet transfers.
- **Verified Security:** Source code 100% verified on BscScan.
